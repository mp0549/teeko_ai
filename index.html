EXPERIMENT BRIEFING

HOW TO PLAY

Teeko is a two-phase strategy game played on a 5×5 grid. Align four of your pieces in a row, column, diagonal, or 2×2 box to win.

GAME PHASES

DROP PHASE 1 — Alternate placing pieces on any empty cell. Ends after all 8 pieces (4 each) are on the board.
MOVE PHASE 2 — Alternate sliding a piece to any adjacent empty cell (8 directions). No new pieces.
DRAW THREEFOLD REPETITION — If the same board position occurs 3 times, the game is declared a draw. The A.I. will seek a draw to avoid defeat when significantly losing.

SYSTEM TELEMETRY

[ MAP ] TERRITORIAL INFLUENCE — Heatmap showing which cells each player controls based on heuristic scoring. Red = A.I., Dark = player.
[ PATH ] SEARCH PATHFINDER — Live animation of minimax branches explored during the A.I.'s turn.
